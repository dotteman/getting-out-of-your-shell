Interactive Edition

This edition has real terminals in it

Every "Live sandbox" box below is a small bash simulator running entirely in your browser — a real (if simplified) shell with its own filesystem, seeded with the exact same practice data as Appendix B's setup script. Type commands, press Enter, and see real output. It supports pipes, redirects, globs, grep/sed/awk, permissions, background jobs, and for/if/while loops.

↑/↓ recall history · Tab completes · Ctrl-C cancels the line · Ctrl-L clears the screen · Ctrl-R searches history · every terminal on the page shares one sandbox, so what you do in Chapter 2 is still there in Chapter 9 — use any "reset sandbox" button to start over everywhere.
