Appendix BLab Setup and Answer Key

The setup script

Save this as setup.sh and run bash setup.sh. It creates ~/shell-lab with every file the labs reference. Run it again any time you want a clean slate (delete ~/shell-lab first).

__SETUP_SCRIPT__
Reset at any time 
$ rm -rf ~/shell-lab && bash setup.sh

Answers

Several labs have more than one correct answer. If yours differs but produces the right result, it is right.

Question 9: echo '$USER' prints the literal text $USER; echo "$USER" prints your username. Single quotes suppress all expansion.

Lab 11 · Scripting

#!/usr/bin/env bash
# greet.sh
set -euo pipefail
name="${1:?usage: $0 NAME}"
echo "Hello, $name"
#!/usr/bin/env bash
# count.sh
set -euo pipefail
dir="${1:?usage: $0 DIRECTORY}"
[[ -d "$dir" ]] || { echo "not a directory: $dir" >&2; exit 1; }
n=$(find "$dir" -maxdepth 1 -type f | wc -l)
echo "$dir contains $n files"
#!/usr/bin/env bash
# ext.sh
set -euo pipefail
for f in data/*; do
  [[ -f "$f" ]] || continue
  base="${f##*/}"                 # strip the path
  ext="${base##*.}"               # strip everything up to the last dot
  [[ "$ext" == "$base" ]] && ext="(none)"
  printf '%-24s %s\n' "$base" "$ext"
done
#!/usr/bin/env bash
# levels.sh
set -euo pipefail
declare -i err=0 warn=0 info=0
while IFS= read -r line; do
  case "$line" in
    *ERROR*) err+=1 ;;
    *WARN*)  warn+=1 ;;
    *INFO*)  info+=1 ;;
  esac
done < logs/app.log
echo "ERROR=$err WARN=$warn INFO=$info"     # ERROR=4 WARN=3 INFO=9
#!/usr/bin/env bash
# backup.sh
set -euo pipefail
src="${1:?usage: $0 DIRECTORY}"
[[ -d "$src" ]] || { echo "no such directory: $src" >&2; exit 1; }
tmp=$(mktemp -d)
trap 'rm -rf "$tmp"' EXIT
name="$(basename "$src")-$(date +%F).tar.gz"
tar -czf "$tmp/$name" "$src"
mkdir -p "$HOME/shell-lab/archive"
cp "$tmp/$name" "$HOME/shell-lab/archive/"
echo "wrote archive/$name"
#!/usr/bin/env bash
# svc.sh
set -euo pipefail
case "${1:-}" in
  start)  echo "would start the service"  ;;
  stop)   echo "would stop the service"   ;;
  status) echo "would report status"      ;;
  *)      echo "usage: $0 {start|stop|status}" >&2; exit 1 ;;
esac

That is the 20%. The rest is repetition — and the repetition is the point. Pick one thing from Chapter 12 and use it deliberately this week; next week pick another. Fluency at the shell is not a body of knowledge you finish acquiring, it is a set of reflexes you build a few seconds at a time.
