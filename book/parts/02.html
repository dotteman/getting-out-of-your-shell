Chapter 2Moving Around

Linux organizes everything into one tree that starts at /, the root. There are no drive letters. A USB stick, a network share, and your hard disk all appear as directories somewhere under /.

Absolute and relative paths

An absolute path starts at the root and works everywhere: /var/log/syslog. A relative path starts from wherever you currently are: log/syslog. Four shorthands do most of the work:

SymbolMeans
.the current directory
..the parent directory
~your home directory
-(with cd) the directory you were in previously
$ cd /var/log        # absolute
$ cd ..              # up one level, now in /var
$ cd -               # back to /var/log
$ cd                 # with no argument: straight home
$ cd ../../etc       # relative, climbing two levels then down

Seeing what is there

$ ls                 # names only
$ ls -l              # long format: permissions, owner, size, date
$ ls -a              # include hidden files (names starting with .)
$ ls -lh             # sizes as 4.0K, 2.3M instead of raw bytes
$ ls -lt             # newest first
$ ls -ltr            # newest last — handy for logs, the interesting line ends up nearest your prompt
$ ls -ld /etc        # info about the directory itself, not its contents

Globbing: patterns instead of names

The shell expands wildcards before running the command. ls *.txt never reaches ls as *.txt — bash replaces it with the list of matching filenames first. This is one of the most important facts in this book, and Chapter 10 returns to it.

PatternMatches
*any characters, including none — *.log, report*
?exactly one character — file?.txt matches file1.txt, not file10.txt
[abc]one character from the set — file[123].txt
[a-z]one character from the range
{a,b}brace expansion — file.{txt,md} becomes two words; unlike the others it works even if no file matches
$ ls *.log                     # every log file here
$ ls report_2026-0[1-6]*.csv   # first half of the year
$ mkdir -p project/{src,test,docs}   # creates three directories in one go
$ echo {1..5}
1 2 3 4 5
Careful

A glob is not a regular expression. In glob syntax * means "anything"; in regex it means "zero or more of the previous thing". grep *.txt and ls *.txt are doing entirely different things with that asterisk. Chapter 7 covers regex properly.

Seeing structure

$ tree -L 2            # directory tree, two levels deep (install if missing)
$ ls -R                 # recursive listing, the always-available fallback
$ du -sh *              # size of each item here, summarized
$ du -sh . | sort -h    # what is eating my disk
$ df -h                 # free space per filesystem

Questions

Why does cd with no arguments not throw an error?

Bare cd is defined to mean "go to $HOME". It is the fastest way home from anywhere. Likewise cd - toggles between the last two directories, which is excellent when you are bouncing between a config directory and a log directory.

ls *.txt prints "no such file or directory: *.txt". What happened?

No file matched the pattern, so bash left the literal string *.txt in place and passed it to ls, which then complained about a file with that odd name. This is standard (and slightly surprising) bash behavior. You can make unmatched globs expand to nothing instead with shopt -s nullglob, but knowing why the error looks like that is usually enough.

What is the difference between ls -l /etc and ls -ld /etc?

ls -l /etc lists the contents of the directory. ls -ld /etc lists the directory entry itself — one line showing /etc's own permissions, owner, and size. Use -d whenever you want to inspect a directory rather than look inside it.

You are in /home/dave/projects/api/src. Write the shortest way to get to /home/dave/projects/web.

cd ../../web — up out of src, up out of api, then down into web. cd ~/projects/web is the same length and arguably clearer; both are fine.

Why is ls -ltr a favorite of experienced admins?

-t sorts by time, -r reverses it, so the most recently modified file appears at the bottom of the output — right above your prompt, where your eyes already are. On a directory with hundreds of log files, that is the file you almost always want.
