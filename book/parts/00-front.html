The 20% of bash that does 80% of the work.

A short, practical book for people who have opened a terminal, felt vaguely uneasy, and closed it again. By the end you will move around a Linux system with confidence, chain commands together, edit text without opening an editor, manage processes and permissions, and write scripts that other people can read.

How to Use This Book

Every chapter follows the same shape: a short explanation, commands you can actually type, a lab that gives you something concrete to do, and a handful of questions whose answers are hidden until you click them. Do the labs. Reading about the shell is like reading about swimming.

You need a Linux or macOS terminal, or WSL on Windows. Check that you are running bash:

$ echo $SHELL
/bin/bash
$ bash --version
GNU bash, version 5.2.21(1)-release

If it says zsh (the default on modern macOS), almost everything here still works — zsh is bash-compatible for the 80% this book covers. Where it matters, the text says so. To follow along in real bash on a Mac, just type bash to start one.

Set up your sandbox first

Every lab runs inside one throwaway directory so you can experiment without fear. Appendix B contains a setup script that builds it — copy that script into a file called setup.sh, then run:

$ bash setup.sh
Sandbox ready at: /home/dave/shell-lab
$ cd ~/shell-lab

Do this before Lab 1. To start over at any point, rm -rf ~/shell-lab and run it again.

Conventions

A line beginning with $ is something you type; the $ is the prompt and is not part of the command. Lines without it are output. Text in ANGLE_BRACKETS or written as FILE is a placeholder you replace with a real value.
